# Three-Graph Agent Safety v1.1 — установка в ChatGPT

Навык сохраняет три главных причинных графа истины:

```text
Идея      — что агент предлагает и предполагает
Намерение — что пользователь действительно разрешил сейчас
Факт      — что независимо доказано
```

И добавляет три контекстных графа:

```text
Политика — какие внешние правила разрешают, запрещают или ограничивают действие
Память   — какой прошлый контекст найден, откуда он взят и не устарел ли
Риск     — какой вред возможен, насколько он вероятен и что останется после защиты
```

Главное правило v1.1:

```text
Память может персонализировать решение,
но не может создавать полномочия.
```

Навык особенно полезен для персональных агентов, платежей, удалений, изменения лимитов, отправки сообщений, GitHub-операций, API-вызовов, timeout, повторов, idempotency и восстановления после частичного сбоя.

## Установка на телефоне

1. Откройте релиз `three-graph-agent-safety-v1.1.0` в ProofPath.
2. Скачайте `three-graph-agent-safety.zip`.
3. В ChatGPT откройте **Настройки → Навыки → Созданные мной**.
4. Нажмите добавление навыка и загрузите ZIP целиком.
5. Не распаковывайте архив перед загрузкой.

## Быстрые команды

```text
Построй шесть графов: идея, намерение, политика, память, риск и факт.
Покажи, какой контекст влияет на решение, но не является разрешением.
```

```text
Проверь, не использует ли агент прошлую память как право отправить сообщение,
купить товар, удалить данные или выполнить другое действие.
```

```text
Разбери timeout после отправки запроса.
Не допускай blind retry, UNKNOWN → SUCCESS и память → новое разрешение.
```

```text
Изучи репозиторий и реализуй Personal Agent Safety Bundle v1.1
со схемой, негативными тестами, evidence и CI.
```

```text
Найди конфликт между текущим намерением пользователя,
политикой, памятью, риском и реальным результатом.
```

## Как выглядит результат

```text
Idea Graph
→ стратегия и предположения

Intent Graph
→ текущее разрешение пользователя

Policy Graph
→ правила и точная ревизия

Memory Graph
→ прошлый контекст, происхождение, свежесть и конфликты

Risk Graph
→ возможный вред, защита и остаточный риск

Fact Graph
→ наблюдаемые события с evidence_refs

Decision
→ ACCEPT / HOLD / BLOCK / UNKNOWN / DIVERGED / VERIFIED
```

До выполнения:

```text
IDEA_INTENT_ALIGNED
+ INTENT_CURRENT
+ POLICY_ALLOWED
+ MEMORY_PROVENANCED
+ RISK_ACCEPTABLE
= ACCEPT
```

После выполнения:

```text
ACCEPT
+ FACT_INDEPENDENTLY_VERIFIED
+ FINAL_INVARIANT_MATCHES_INTENT
= SAFE_COMPLETION
```

## Важно

Навык не является системной песочницей и не создаёт полномочия сам. Память, профиль пользователя, прошлое согласие и низкая оценка риска не заменяют текущее разрешение. Реальные побочные эффекты должны оставаться за внешней системой авторизации, sandbox/VM/container и authoritative system of record.
