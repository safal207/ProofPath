# Three-Graph Agent Safety — установка в ChatGPT

Навык разделяет любую важную операцию агента на три причинных графа:

```text
Идея      — что агент предлагает и почему
Намерение — что пользователь реально разрешил
Факт      — что доказуемо произошло
```

Он особенно полезен для платежей, удалений, изменения лимитов, отправки сообщений, GitHub-операций, API-вызовов, timeout, повторов, idempotency и восстановления после частичного сбоя.

## Установка на телефоне

1. Откройте релиз `three-graph-agent-safety-v1.0.0` в ProofPath.
2. Скачайте `three-graph-agent-safety.zip`.
3. В ChatGPT откройте **Настройки → Навыки → Созданные мной**.
4. Нажмите добавление навыка и загрузите ZIP целиком.
5. Не распаковывайте архив перед загрузкой.

## Быстрые команды

```text
Построй три графа: идея, намерение и факт для этого сценария.
```

```text
Проверь, где идея агента разошлась с разрешением пользователя и реальным результатом.
```

```text
Разбери timeout после отправки запроса. Не допускай blind retry и UNKNOWN → SUCCESS.
```

```text
Изучи репозиторий и реализуй Idea–Intent–Fact evidence chain с тестами и CI.
```

```text
Создай машинно-читаемые три графа, alignment, mismatch report и независимую проверку.
```

## Как выглядит результат

```text
Idea Graph
→ предполагаемая безопасная стратегия

Intent Graph
→ действующая власть, область и запреты

Fact Graph
→ события с evidence_refs

Alignment
→ сопоставление трёх графов

Decision
→ ACCEPT / HOLD / BLOCK / UNKNOWN / DIVERGED / VERIFIED
```

Финальный успех допускается только при:

```text
IDEA_ALIGNED
+ INTENT_AUTHORIZED
+ FACT_INDEPENDENTLY_VERIFIED
= SAFE_COMPLETION
```

## Важно

Навык не является системной песочницей и не создаёт полномочия сам. Он помогает моделировать, проверять и документировать безопасное выполнение. Реальные побочные эффекты должны оставаться за внешней системой авторизации, sandbox/VM/container и authoritative system of record.
